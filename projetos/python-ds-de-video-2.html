Control Flow

Introduction to Python · Vídeo 2 de 13

Em desenvolvimento

Este módulo mostra como o Python decide quais linhas de código executar e quais ignorar. Ao final, é possível descrever o fluxo de controle de um programa, explicar como if, elif, else e pass alteram a ordem de execução, explicar o papel da indentação e combinar operadores booleanos e de comparação em condições expressivas.

Os trechos de código abaixo são exemplos escritos por mim com base no que a demonstração descreve, não a cópia do notebook do curso. O ambiente é o mesmo do módulo anterior: Serverless Environment Version 5, com o ambiente base em Standard Version 5.

if e else: escolhendo um caminho

Por padrão, o Python executa o código sequencialmente, de cima para baixo. A instrução if altera esse fluxo: avalia uma expressão booleana e escolhe um de dois caminhos. Se a expressão for True, executa o bloco 1. Se não for, executa o bloco 2, do else.

if True:
    print("true")
else:
    print("false")     # se fosse "if False:", este bloco é que rodaria

Um exemplo mais prático da demonstração: uma célula cria um widget de texto no topo do notebook, que pede um número de 1 a 10. Digitando 8, outra célula lê a entrada como inteiro e verifica se ela está entre 1 e 10, imprimindo Valid Input ou Invalid Input.

numero = 8

if numero >= 1 and numero <= 10:
    print("Valid Input")
else:
    print("Invalid Input")

A indentação faz parte da sintaxe

No Python, a indentação não é enfeite: é ela que define quais linhas pertencem ao bloco de um if ou else. Com a indentação errada, o código pode se comportar de forma inesperada ou dar um erro de indentação (IndentationError).

  • O padrão são 4 espaços para cada nível de indentação.
  • Na maioria dos editores, a tecla Tab insere o espaçamento correto.

Operadores de comparação

As condições usam expressões booleanas. Além dos operadores lógicos and, or e not, existem os operadores de comparação:

OperadorSignificado
==igual a
!=diferente de
< e >menor que e maior que
<= e >=menor ou igual a e maior ou igual a

Atenção: o sinal de igual simples (=) é para atribuir valor a uma variável. A comparação de igualdade usa o igual duplo (==).

print(1 == 1)          # True
print(1.5 != 2.5)      # True
print("abc" == "xyz")  # False
print(True == True)    # True

Aninhamento: um if dentro de outro

O código dentro de um bloco if ou else pode ser qualquer Python válido, inclusive outro if. Isso se chama aninhamento. O exemplo da demonstração é a decisão de comprar um almoço, com orçamento de US$ 15 e um almoço que custa US$ 20:

preco_almoco = 20

if preco_almoco <= 15:
    print("Vamos comprar")
else:
    if preco_almoco < 25:
        print("Is it really good?")
    else:
        print("This better be the best food of all time")

Com o preço em 20, a saída é Is it really good?.

elif: encadear sem aumentar a indentação

A palavra-chave elif permite encadear várias condições sem criar níveis a mais de indentação. O Python as avalia de cima para baixo e para na primeira condição verdadeira. Se nenhuma for verdadeira, executa o else, se houver.

preco_almoco = 15

if preco_almoco == 10:
    print("Vamos comprar")
elif preco_almoco <= 15:
    print("Vamos comprar mesmo assim")
elif preco_almoco < 25:
    print("Is it really good?")
else:
    print("This better be the best food of all time")

Com o preço em 15, a primeira condição falha e a segunda é verdadeira, então o Python imprime a mensagem de compra e não avalia as demais.

pass: o espaço reservado

Às vezes é útil esboçar a estrutura do programa antes de escrever a lógica. A instrução pass é um espaço reservado que não faz nada (no-op), mas mantém o código sintaticamente válido. Não gera saída nem erro, e funciona como um marcador de tarefa pendente.

if preco_almoco <= 15:
    pass   # a lógica entra aqui depois
else:
    pass   # e aqui também

Juntando tudo: recomendando uma raça de cachorro

O programa combina if, elif, operadores de comparação e lógica booleana com três entradas: dog_person e cat_person (booleanos) e age (inteiro). Quem tem menos de 18 anos precisa pedir permissão aos pais. Para os demais, a recomendação depende das duas primeiras:

dog_personcat_personSaída
TrueTrueGolden Retriever, porque se dá bem com gatos
TrueFalseScottish Deerhound
FalseTrueYou're barking up the wrong tree.
FalseFalseAre you sure a pet is right for you?

Versão aninhada

dog_person = True
cat_person = True
age = 30

if age < 18:
    print("Ask your parents for permission")
else:
    if dog_person and cat_person:
        print("Golden Retriever")
    else:
        if dog_person and not cat_person:
            print("Scottish Deerhound")
        else:
            if cat_person and not dog_person:
                print("You're barking up the wrong tree.")
            else:
                print("Are you sure a pet is right for you?")

Versão achatada (flattening)

A mesma lógica pode ser escrita de forma mais concisa trocando a estrutura aninhada por elif. Esse processo se chama achatamento (flattening). O código fica bem mais fácil de ler e evita os níveis de indentação que podem se multiplicar quando há muitos if e else. Nos dois casos, a saída é Golden Retriever.

if age < 18:
    print("Ask your parents for permission")
elif dog_person and cat_person:
    print("Golden Retriever")
elif dog_person:
    print("Scottish Deerhound")
elif cat_person:
    print("You're barking up the wrong tree.")
else:
    print("Are you sure a pet is right for you?")

Gerando o código com o Genie Code

O Genie Code é o assistente de IA integrado ao Databricks, o mesmo colega de IA visto no treinamento Fundamentals. Ele gera a mesma lógica a partir de um prompt em linguagem natural.

  • Para acessá-lo, clique no assistente do lado direito, chamado Genie Code.
  • Na parte inferior, selecione Agent, não Chat.
  • Também é possível abrir uma célula do Genie Code no notebook: ao adicionar uma célula, as opções são código (Python), texto (markdown) e Genie Code. Cole o prompt e clique em Generate.
  • O código gerado pode ser aceito e executado. Na demonstração, ficou muito parecido, se não idêntico, ao escrito à mão, e um segundo prompt gerou a versão achatada com elif.

Boas práticas para prompts

  • Descrever o objetivo com clareza.
  • Especificar variáveis, datasets e colunas.
  • Indicar as preferências de saída.
  • Fazer perguntas de acompanhamento.

O que guardar: if escolhe o caminho a partir de uma expressão booleana, a indentação (4 espaços) define o bloco, elif encadeia condições sem aninhar e para na primeira verdadeira, e pass segura o lugar da lógica que ainda não existe. Os operadores de comparação (==, !=, <, >, <=, >=) se combinam com and, or e not. O próximo módulo trata das funções.
