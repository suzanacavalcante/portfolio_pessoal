Data Visualization

Introduction to Python · Vídeo 11 de 13

Em desenvolvimento

Olhar os números nem sempre basta: gráficos mostram formas, grupos e valores fora do padrão que uma tabela esconde. Este módulo apresenta três formas de visualizar dados com o dataset do Airbnb de San Francisco: o display() do Databricks para exploração interativa, a plotagem direto do Pandas (histograma e box plot) e o Seaborn (scatter e regression plot), com o cálculo da correlação de Pearson no SciPy.

Os trechos de código abaixo são exemplos escritos por mim com base no resumo da demonstração, não a cópia do notebook do curso. Para poderem ser executados por quem ler, eles usam dados sintéticos gerados no próprio código, em vez do dataset do curso. Por isso os valores que você obtiver serão diferentes dos citados na demonstração, e esses aparecem só no texto.

Setup

O ambiente é o de sempre: Serverless Environment Version 5, com o ambiente base em Standard Version 5. A célula de configuração carrega os datasets e cria o objeto DA. Depois conferem-se o usuário, o catálogo (dbacademy) e o schema (labuser...), e listam-se as tabelas ca_housing e sf_airbnb. Por fim, importa-se o Pandas e carrega-se o DataFrame do Airbnb.

Para os exemplos abaixo, os dados sintéticos são estes:

import numpy as np
import pandas as pd

rng = np.random.default_rng(42)

bedrooms = rng.choice([0, 1, 2, 3, 4], size=300, p=[0.1, 0.5, 0.25, 0.1, 0.05])
bathrooms = np.clip(bedrooms * 0.4 + rng.normal(1, 0.5, size=300), 0.5, None)

df = pd.DataFrame({"bedrooms": bedrooms, "bathrooms": bathrooms.round(1)})

display(): visualização interativa

O display(df), exclusivo do Databricks, gera uma tabela interativa: as URLs ficam clicáveis, e os valores ausentes aparecem como null. Dela dá para criar um gráfico sem escrever código:

  1. Clicar no + ao lado de "Table" e escolher Visualization.
  2. O tipo padrão é um gráfico de barras, e há uma opção horizontal.
  3. Colocar neighborhood no eixo X e bedrooms no Y, mudando a agregação de soma para média. O resultado é a média de quartos por bairro, a maioria entre 1 e 2.
  4. Ao clicar em Save, o Databricks processa o dataset completo, e não só uma amostra de cerca de 1.000 linhas.

O menu do gráfico permite baixar, remover, duplicar, renomear, editar e adicionar a um dashboard.

display(df)   # no Databricks: tabela interativa, com o + para criar gráficos

Plotagem com Pandas

Plotar em código é reprodutível, automatizável e pronto para relatórios. O Pandas usa o Matplotlib por baixo, sem precisar de um import separado, e o visual é mais básico que o do Seaborn.

Histograma

O hist() divide os valores em intervalos (bins) e conta as observações de cada um. Ajuda a ver agrupamentos, simetria ou assimetria, lacunas e valores fora do padrão (outliers).

df["bedrooms"].hist()          # bins padrão
df["bedrooms"].hist(bins=20)   # visão mais fina
  • No dataset do curso, a distribuição é assimétrica à direita: o pico fica em 1 quarto e a cauda segue para a direita. A maioria das listagens é de quartos individuais e estúdios.
  • Há mais de 4.000 listagens de 1 quarto e um pico menor em 2.
  • Em variáveis discretas, os bins se alinham às contagens. Poucos bins perdem detalhe, e muitos geram ruído.

Box plot

O box plot mostra cinco números: mínimo, Q1, mediana, Q3 e máximo.

df.boxplot(column=["bedrooms", "bathrooms"])
  • A caixa vai de Q1 a Q3 (o IQR, os 50% centrais dos dados).
  • Os whiskers chegam até 1,5 vez o IQR.
  • Pontos além disso são outliers, como as listagens de 5 e 6 quartos do dataset do curso.

Regra prática: use o histograma para ver a forma completa da distribuição de uma variável, e o box plot para comparar vários grupos ou variáveis lado a lado.

Seaborn

O Seaborn é construído sobre o Matplotlib e produz gráficos mais refinados, com qualidade de publicação. O alias convencional é sns.

Scatter plot

Cada ponto é uma listagem, e o gráfico mostra a relação entre duas variáveis.

import seaborn as sns

sns.scatterplot(data=df, x="bedrooms", y="bathrooms")

O que se vê no dataset do curso:

  • uma tendência positiva: mais quartos, mais banheiros;
  • pontos em colunas discretas, porque o número de quartos é inteiro;
  • bastante dispersão;
  • um outlier com 14 quartos e 14 banheiros.

Regression plot

O regplot acrescenta a linha de melhor ajuste e uma faixa sombreada de intervalo de confiança. Faixa estreita significa alta confiança, e faixa larga significa incerteza. No exemplo do curso, a faixa se alarga nos extremos, onde há menos dados. A inclinação é claramente positiva, mas ainda falta quantificar a força da relação.

sns.regplot(data=df, x="bedrooms", y="bathrooms")

Correlação de Pearson com o SciPy

O coeficiente r resume o quanto duas variáveis se movem juntas em linha reta. Ele vai de -1 (relação negativa perfeita) a +1 (positiva perfeita), e a demonstração traz uma tabela de interpretação, de positivo muito forte a negativo muito forte.

O Pearson não aceita valores nulos, então se cria antes uma cópia sem eles com dropna():

from scipy import stats

clean_df = df[["bedrooms", "bathrooms"]].dropna()
r_value, p_value = stats.pearsonr(clean_df["bedrooms"], clean_df["bathrooms"])

print(r_value)   # coeficiente de correlação
print(p_value)   # significância estatística
Resultado no dataset do cursoLeitura
r ≈ 0,412Correlação positiva moderada
p-value minúsculoEstatisticamente significativo. Com milhares de listagens, até correlações moderadas são confiáveis

Ressalva: o Pearson mede só relações lineares. Por isso o número deve sempre vir acompanhado de uma checagem visual, como o regplot.

O que guardar: o display() é o caminho rápido e interativo no Databricks, e o Pandas plota distribuições direto do DataFrame. O Seaborn mostra relações entre variáveis com mais refinamento. O coeficiente de Pearson quantifica o que o gráfico sugere, mas só para relações lineares, e deve vir com a checagem visual.
