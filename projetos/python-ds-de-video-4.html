Collection Types and Methods

Introduction to Python · Vídeo 4 de 13

Em desenvolvimento

Até aqui os módulos trataram de valores únicos: inteiros, floats, strings e booleanos. Este módulo mostra como agrupar vários valores com os tipos de coleção do Python: listas, dicionários e tuplas. Antes disso, duas ideias de base: objetos e métodos.

Os trechos de código abaixo são exemplos escritos por mim com base no que a demonstração descreve, não a cópia do notebook do curso. O ambiente é o mesmo dos módulos anteriores: Serverless Environment Version 5, com o ambiente base em Standard Version 5.

Objetos e métodos

No Python, todo valor é um objeto. O número 1 é um objeto inteiro, e o texto "Hello" é um objeto string. Isso importa porque o tipo do objeto determina o que se pode fazer com ele: uma string faz coisas de string, uma lista faz coisas de lista. É também por isso que o Python não deixa somar uma string com um inteiro sem converter antes.

Um método é uma função que pertence a um tipo de objeto. Em vez de chamá-lo sozinho, como print ou help, ele é chamado no próprio objeto com a notação de ponto: o objeto, o ponto, o método e, às vezes, argumentos entre parênteses.

Métodos de string

greeting = "hello"
print(greeting.upper())   # HELLO
print(greeting)           # hello: o original não mudou

O upper não alterou a string original: ele criou e devolveu uma nova string. Isso leva a uma distinção importante:

Tipo de métodoO que fazExemplo
Non-in-placeDevolve um novo objeto e deixa o original intactogreeting.upper()
In-placeAltera diretamente o objeto em que é chamadolista.append(x)

Manter essa distinção ajuda a entender por que algumas chamadas de método precisam de reatribuição e outras não.

Descobrindo os métodos de um objeto

Como saber quais métodos um objeto tem? No Databricks, ao digitar o nome do objeto seguido de um ponto, aparece a lista de métodos disponíveis. Com Tab, o método é preenchido automaticamente. Não é só conveniência, é uma ferramenta de aprendizado: dá para explorar de forma interativa em vez de memorizar tudo antes. E o help explica cada método.

help(greeting.capitalize)       # documentação do método
print(greeting.capitalize())    # Hello

Listas

Uma lista é uma das formas mais comuns de guardar vários valores juntos. É criada com colchetes e é ordenada: o Python lembra a posição de cada item, e essa ordem importa para o índice e o fatiamento. Também é flexível, e pode misturar strings, booleanos, inteiros e floats.

breakfast_list = ["pancakes", "eggs", "waffles"]
print(breakfast_list)         # ['pancakes', 'eggs', 'waffles']
print(type(breakfast_list))   # <class 'list'>

Adicionando itens: append e o operador +

O método append adiciona um item ao final da lista, e altera a lista original (in-place). Já o operador + concatena duas listas e cria uma nova lista combinada.

breakfast_list.append("yogurt")
print(breakfast_list)   # ['pancakes', 'eggs', 'waffles', 'yogurt']

print(["pancakes", "eggs"] + ["waffles", "yogurt"])
# ['pancakes', 'eggs', 'waffles', 'yogurt']

Para somar um item a uma lista existente, ele precisa estar dentro de outra lista. O += é um atalho para somar e reatribuir à própria variável. Para quem está começando, vale ler como "adicione isto e guarde o resultado aqui".

breakfast_list = ["pancakes", "eggs", "waffles"]

breakfast_list = breakfast_list + ["yogurt"]   # forma completa
# breakfast_list += ["yogurt"]                 # atalho, mesmo resultado

Tamanho com len

A função len, vista com strings, também conta os itens de uma lista, o que é prático quando ela é longa demais para olhar item por item.

print(len(breakfast_list))   # 4

Indexação

As listas usam indexação baseada em 0: o primeiro item é o índice 0. Números negativos contam a partir do fim: -1 é o último item, e -2 é o penúltimo.

print(breakfast_list[0])    # pancakes
print(breakfast_list[-1])   # yogurt
print(breakfast_list[-2])   # waffles

Fatiamento (slicing)

O fatiamento pega um intervalo de itens. A sintaxe é lista[início:fim:passo]: o início é a posição inicial, o fim é a posição de parada (e esse item não entra) e o passo diz de quantos em quantos itens pular.

print(breakfast_list[0:2])     # ['pancakes', 'eggs']: o índice 2 fica de fora
print(breakfast_list[0:4:2])   # ['pancakes', 'waffles']: pula um sim, outro não
print(breakfast_list[::2])     # ['pancakes', 'waffles']: início e fim em branco

print(breakfast_list[:2])      # ['pancakes', 'eggs']: do começo até o índice 2
print(breakfast_list[1:])      # ['eggs', 'waffles', 'yogurt']: do índice 1 até o fim

print(breakfast_list[::-1])    # lista invertida

Partes do slice podem ficar em branco. E um passo de -1 inverte a lista, o que é diferente de pegar só o último item.

Substituindo itens e o operador in

Como a lista é modificável, um item pode ser trocado por reatribuição a um índice. E o operador in faz uma pergunta de sim ou não: o item está na lista?

print(breakfast_list)           # ['pancakes', 'eggs', 'waffles', 'yogurt']
breakfast_list[0] = "sausage"
print(breakfast_list)           # ['sausage', 'eggs', 'waffles', 'yogurt']

print("waffles" in breakfast_list)   # True

Dicionários

Um dicionário guarda dados como pares chave-valor (key-value), em vez de uma sequência ordenada. É útil quando cada valor tem um rótulo: em vez de lembrar em que posição o item está, recupera-se pelo nome. A sintaxe usa chaves, com chave: valor separados por vírgula.

Cada chave aponta para exatamente um valor, por isso as chaves precisam ser únicas: se a mesma chave aparecesse duas vezes, o Python não saberia qual valor deveria prevalecer.

breakfast = {"pancakes": 1, "eggs": 2, "waffles": 3}

rates = {"GBP": 0.79, "JPY": 149.50, "EUR": 0.93}   # o dicionário do módulo anterior

Métodos de dicionário

  • get: devolve o valor associado a uma chave. A notação de colchetes faz o mesmo.
  • keys: mostra todas as chaves.
  • items: mostra cada par chave-valor. Esses dois métodos ficam especialmente úteis no próximo módulo, para percorrer dicionários com loops.
print(breakfast.get("waffles"))   # 3
print(breakfast["waffles"])       # 3: o mesmo, com colchetes

print(breakfast.keys())    # dict_keys(['pancakes', 'eggs', 'waffles'])
print(breakfast.items())   # dict_items([('pancakes', 1), ('eggs', 2), ('waffles', 3)])

Atualizando um dicionário

Atribuir a uma chave que já existe sobrescreve o valor. Atribuir a uma chave que não existe cria um novo par.

print(breakfast)                # {'pancakes': 1, 'eggs': 2, 'waffles': 3}
breakfast["waffles"] += 1       # a chave existe: o valor é sobrescrito (4)
breakfast["yogurt"] = 1         # a chave não existe: um novo par é criado
print(breakfast)                # {'pancakes': 1, 'eggs': 2, 'waffles': 4, 'yogurt': 1}

O operador in também funciona com dicionários, e verifica se uma chave existe:

print("bacon" in breakfast.keys())   # False
print("bacon" in breakfast)           # False: o mesmo, sem chamar keys()

Tuplas

Uma tupla é parecida com uma lista, pois guarda uma sequência ordenada de itens. A grande diferença é que as tuplas são imutáveis: depois de criadas, o conteúdo não pode ser alterado. Elas são definidas com parênteses. Índice, fatiamento e o operador in funcionam como nas listas.

breakfast = ("pancakes", "eggs", "waffles")

print(breakfast[0])           # pancakes
print(breakfast[1:3])         # ('eggs', 'waffles')
print("pancakes" in breakfast)   # True

# breakfast[0] = "sausage"    # TypeError: tuplas não aceitam atribuição

O que guardar: todo valor é um objeto, e os métodos são comportamentos anexados a ele pela notação de ponto. Métodos non-in-place devolvem um novo objeto, e os in-place alteram o original. Listas guardam sequências ordenadas e modificáveis, dicionários guardam dados rotulados em pares chave-valor, e tuplas guardam dados ordenados que permanecem fixos.
