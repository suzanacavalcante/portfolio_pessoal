Classes

Introduction to Python · Vídeo 7 de 13

Em desenvolvimento

Este módulo apresenta as classes, a base da programação orientada a objetos no Python. Ao final, é possível definir e instanciar classes, usar atributos de instância, criar métodos, entender o papel do self e distinguir uma função de um método. Também aparece a herança, que permite reaproveitar código entre classes.

Os trechos de código abaixo são exemplos escritos por mim com base no resumo da demonstração, não a cópia do notebook do curso. O ambiente é o mesmo dos módulos anteriores: Serverless Environment Version 5.

O que é uma classe

Uma classe é um modelo para criar objetos. Uma boa imagem é a do cortador de biscoitos: ele define o formato, mas não é o biscoito. Os valores que já usamos são instâncias de classes integradas: 42 é uma instância de int, "hello" de str e [1, 2, 3] de list.

A sintaxe é class NomeDaClasse():, com o nome em Pascal case (CapWords): cada palavra com inicial maiúscula e sem sublinhados.

Instanciação

Uma classe com só um pass cria apenas o modelo, sem comportamento. Instanciar é chamar a classe como se fosse uma função, o que cria um objeto. A função type mostra de qual classe ele é, e no notebook a classe aparece como __main__.Dog.

class Dog:
    pass

my_dog = Dog()          # instanciação
print(type(my_dog))     # <class '__main__.Dog'>

O padrão de trabalho é: definir a classe, instanciar e usar a instância.

Funções são objetos de primeira classe

No Python, funções também são objetos. Atribuir uma função a outra variável sem parênteses não a executa: só dá um segundo nome a ela.

def greet():
    print("Hello!")

say_hello = greet   # sem parênteses: outro nome para a mesma função
say_hello()         # Hello!

Isso importa porque métodos são funções guardadas como atributos da classe.

Métodos

Um método é uma função que pertence a uma classe. Ele fica indentado dentro da classe, o primeiro parâmetro é sempre self, e é chamado no objeto com a notação de ponto: objeto.metodo(argumentos).

class Dog:
    def bark(self):
        print("Woof!")

my_dog = Dog()
my_dog.bark()   # Woof!

O papel do self

  • Nunca se passa o self explicitamente: o Python passa o próprio objeto automaticamente.
  • O self não é uma palavra-chave, é uma convenção, seguida por todo mundo.
  • Ele representa a instância que chamou o método.

Para ver isso, o exemplo da demonstração imprime o mesmo endereço de memória dentro e fora do método:

class Dog:
    def show_self(self):
        print(id(self))      # endereço do objeto, visto de dentro do método

my_dog = Dog()
my_dog.show_self()
print(id(my_dog))            # o mesmo número: self e my_dog são o mesmo objeto

Atributos e o __init__

O __init__ (chamado de dunder, por causa dos dois sublinhados de cada lado) é o construtor: roda automaticamente ao criar a instância. O padrão é receber os argumentos e guardá-los na instância com self.arg = arg.

class DogWithAttributes:
    def __init__(self, name, color):
        print("__init__ executou")
        self.name = name
        self.color = color

my_dog = DogWithAttributes("Rex", "brown")   # imprime: __init__ executou

O print dentro do construtor confirma que ele roda sozinho, sem ninguém chamá-lo.

Acessando atributos

Os atributos são acessados com a notação de ponto sem parênteses: my_dog.name. Cada instância tem os seus próprios valores. Os métodos leem os atributos pelo self.

class DogWithAttributes:
    def __init__(self, name, color):
        self.name = name
        self.color = color

    def return_name(self):
        return self.name

    def return_color(self):
        return self.color

my_dog = DogWithAttributes("Rex", "brown")
print(my_dog.name)            # Rex
print(my_dog.return_color())  # brown

Atualizando atributos

Um método pode alterar o estado do objeto. Aqui, update_name guarda um novo nome em self.name. A mudança vale só para aquela instância: um segundo cachorro não é afetado.

class DogWithAttributes:
    def __init__(self, name, color):
        self.name = name
        self.color = color

    def update_name(self, new_name):
        self.name = new_name

my_dog = DogWithAttributes("Rex", "brown")
other_dog = DogWithAttributes("Fido", "black")

my_dog.update_name("Ruffles")
print(my_dog.name)      # Ruffles
print(other_dog.name)   # Fido: não foi afetado

Interação entre instâncias

Um método também pode receber outro objeto como argumento e usar os atributos dele, ao lado dos do próprio self.

class DogWithAttributes:
    def __init__(self, name, color):
        self.name = name
        self.color = color

    def return_both_names(self, other_dog_object):
        return f"{self.name} and {other_dog_object.name}"

rex = DogWithAttributes("Rex", "brown")
ruffles = DogWithAttributes("Ruffles", "black")
print(rex.return_both_names(ruffles))   # Rex and Ruffles

Herança

A herança permite criar uma classe a partir de outra, com a sintaxe class Filha(Pai):. A classe filha também é chamada de subclasse, e a classe pai de superclasse. A filha pode reaproveitar, sobrescrever e estender o que herda. Para chamar o construtor da pai, usa-se super().__init__().

O exemplo da demonstração tem uma classe Animal com o método speak(), um Dog que herda de Animal (som "woof", uma cor e o método fetch()) e um Cat que herda de Animal (som "meow").

class Animal:
    def __init__(self, name, sound):
        self.name = name
        self.sound = sound

    def speak(self):
        print(f"{self.name} says {self.sound}")

class Dog(Animal):
    def __init__(self, name, color, sound="woof"):
        super().__init__(name, sound)   # reaproveita o construtor da pai
        self.color = color

    def fetch(self):                    # método só do Dog: estende a pai
        print(f"{self.name} fetches the ball")

class Cat(Animal):
    def __init__(self, name, sound="meow"):
        super().__init__(name, sound)

my_dog = Dog("Rex", "brown")
my_cat = Cat("Mia")

my_dog.speak()   # Rex says woof
my_cat.speak()   # Mia says meow
my_dog.fetch()   # Rex fetches the ball

my_dog.sound = "Bark"   # sobrescreve o atributo só nesta instância
my_dog.speak()          # Rex says Bark

A vantagem é que a lógica comum fica em um só lugar: uma correção na classe pai vale para todas as filhas.

O que guardar: a classe é o modelo, e o objeto é a instância criada a partir dele. Métodos são funções da classe, e recebem o self automaticamente. O __init__ constrói a instância e guarda os atributos, que são acessados com ponto e sem parênteses, e cada instância tem os seus. Na herança, a filha reaproveita, sobrescreve e estende a pai, com o super(). O próximo módulo trata de instalar, importar e usar bibliotecas do Python.
