Em desenvolvimento

Este é o módulo mais longo do treinamento, com cerca de 42 minutos, e mostra o fluxo de trabalho completo com um dataset real no Pandas: ler um CSV, inspecionar, converter e formatar datas, renomear colunas, filtrar linhas, agregar e agrupar, ordenar, tratar valores ausentes e gravar o resultado de volta em CSV.

Os trechos de código abaixo são exemplos escritos por mim com base no resumo da demonstração, não a cópia do notebook do curso. Em vez do dataset do curso, usei um DataFrame pequeno e inventado, no estilo do dataset de imóveis do Airbnb de San Francisco, para os exemplos poderem ser executados por quem ler. Os números do dataset real (7.150 linhas, 106 colunas e outros) aparecem no texto, como foram citados na demonstração.

Lendo e inspecionando dados

Na prática, os dados vêm de arquivos (CSV, Parquet, Excel, JSON), e o Pandas tem uma função read_* para cada formato. Para um CSV, usa-se pd.read_csv(caminho), com o caminho montado com uma f-string a partir do catálogo e do schema do usuário.

caminho = f"/Volumes/{DA.catalog_name}/{DA.schema_name}/datasets/airbnb/..."
df = pd.read_csv(caminho)

df.head()      # as 5 primeiras linhas (o padrão); df.head(10) mostra 10
df.tail(3)     # as 3 últimas linhas

O dataset do curso tem 7.150 linhas e 106 colunas, com strings e valores NaN.

Colunas e tipos

O df.columns mostra só parte dos nomes quando há muitas colunas. Para ver todos, list(df.columns). O df.dtypes mostra os tipos: object (texto ou misto), int64, float64, bool e datetime64.

Um problema comum em CSV: as datas, como first_review e last_review, chegam como object, ou seja, texto. Assim não dá para ordenar cronologicamente, calcular diferenças de tempo nem extrair ano ou mês.

print(df["first_review"].dtype)   # object: ainda é texto

Datas

A conversão é feita com pd.to_datetime, que gera uma coluna datetime64. Para exibir a data em outro formato, o acessor .dt.strftime usa códigos: %m é o mês, %d o dia e %Y o ano com 4 dígitos. Os separadores são literais.

df["first_review"] = pd.to_datetime(df["first_review"])
print(df["first_review"].dtype)   # datetime64[ns]

formatada = df["first_review"].dt.strftime("%m-%d-%Y")
print(formatada.tolist())   # ['03-01-2015', '07-15-2016', '11-30-2014', '01-20-2017', '05-09-2013']

Atenção: o strftime devolve texto (object). Para fazer contas com datas, mantenha a coluna datetime64 original e use a formatada só para exibir.

Renomeando colunas

O rename recebe um dicionário de nomes antigos para novos. Só as colunas citadas mudam, e o resultado precisa ser reatribuído, senão o original fica intacto. O exemplo da demonstração troca neighbourhood por neighborhood.

df = df.rename(columns={"neighbourhood": "neighborhood"})
print(df.columns.tolist()[0])   # neighborhood

Filtrando linhas

Uma máscara booleana mantém só as linhas em que a condição é True. Os índices das linhas descartadas somem do resultado, e o != inverte o filtro.

superhosts = df[df["host_is_superhost"] == "t"]       # linhas 0, 2 e 4
nao_superhosts = df[df["host_is_superhost"] != "t"]   # linhas 1 e 3

Para várias condições, os operadores and, or e not do Python não servem, porque só funcionam com um único booleano. Usam-se os operadores bitwise, com cada condição entre parênteses:

OperadorSignifica
&and (e)
|or (ou)
~not (não)
 
df[(df["host_is_superhost"] == "t") & (df["number_of_reviews"] >= 150)]   # linhas 0 e 2
df[(df["bedrooms"] == 0) | (df["bedrooms"] >= 3)]                          # linhas 1 e 3
df[~(df["host_is_superhost"] == "t")]                                       # linhas 1 e 3

Agregações e describe

Funções como mean, min, max, count e std reduzem uma coluna a um único valor. Na demonstração, number_of_reviews tem média de 43,5, mínimo 0 e máximo 677. Em Python puro seria preciso fazer sum / count à mão. O Pandas ignora o NaN por padrão.

reviews = df["number_of_reviews"]
print(reviews.mean())    # 80.0
print(reviews.min())     # 0
print(reviews.max())     # 200
print(reviews.count())   # 5
print(round(reviews.std(), 2))   # 89.72

O describe() resume uma coluna numérica de uma vez: count, mean, std, min, os quartis (25%, 50% e 75%, sendo o 50% a mediana) e max. O .round(2) reduz as casas decimais.

print(df[["bedrooms", "number_of_reviews"]].describe().round(2))
#        bedrooms  number_of_reviews
# count      5.00               5.00
# mean       1.40              80.00
# std        1.14              89.72
# min        0.00               0.00
# 25%        1.00              10.00
# 50%        1.00              40.00
# 75%        2.00             150.00
# max        3.00             200.00

groupby

O groupby segue o padrão split, apply, combine: divide os dados em grupos, aplica uma função em cada um e combina os resultados. Sozinho, df.groupby("neighborhood") só cria um objeto, sem agregar nada. É a agregação que devolve o resultado.

A coluna agrupada vira o índice. O reset_index() a devolve como coluna comum e restaura o índice inteiro, o que é útil antes de exportar ou transformar.

media = df.groupby("neighborhood")["bedrooms"].mean()
print(media)
# neighborhood
# Mission     0.5
# Nob Hill    1.0
# SoMa        2.5

print(media.reset_index())
#   neighborhood  bedrooms
# 0      Mission       0.5
# 1     Nob Hill       1.0
# 2         SoMa       2.5

Ordenando

O sort_values ordena de forma ascendente por padrão, e o ascending=False ordena do maior para o menor. Na demonstração, bedrooms = 0 pode indicar estúdios, e o máximo do dataset é 14 quartos.

df.sort_values("bedrooms")                    # do menor para o maior
df.sort_values("bedrooms", ascending=False)   # do maior para o menor

Valores ausentes

No Pandas, o NaN indica ausência. Há três estratégias: identificar, descartar ou preencher.

Identificar

print(df[["security_deposit", "notes"]].isna().sum())
# security_deposit    2
# notes               3

No dataset do curso, o resultado aproximado foi de cerca de 1.500 ausentes em security_deposit e 2.744 em notes.

Descartar

O dropna() remove as linhas que têm qualquer NaN. Na demonstração, sobraram 3.623 linhas. É a "opção nuclear", aceitável quando os ausentes são poucos (menos de 5%) e aleatórios.

sem_ausentes = df.dropna()
print(len(sem_ausentes))   # 1: só a linha 0 não tem nenhum NaN

Preencher

O fillna troca os ausentes por um valor. Para colunas numéricas, em geral a média, a mediana ou 0. Para categóricas, a moda ou um rótulo como "missing". Sem inplace, ele devolve um novo DataFrame.

preenchido = df.fillna({"security_deposit": "$0.00", "notes": "missing"})
print(preenchido[["security_deposit", "notes"]].isna().sum())   # 0 e 0

Salvando e relendo CSV

O to_csv grava o DataFrame. Com index=False, o índice não vira uma coluna extra no arquivo.

df.to_csv("/caminho/para/saida.csv", index=False)

relido = pd.read_csv("/caminho/para/saida.csv")
print(relido["first_review"].dtype)   # object: a data voltou como texto
  • O volume de origem é somente leitura, então a demonstração grava em um caminho temporário. Em um fluxo real, grave no seu volume ou no armazenamento em nuvem.
  • Ao reler, as colunas de data voltam como string, e é preciso aplicar o pd.to_datetime de novo. A precisão numérica também pode ser arredondada.
  • O CSV continua sendo o formato universal de intercâmbio, mas em produção vale considerar outros formatos.
