O que é uma rede neural?

Um modelo matemático inspirado no cérebro: neurônios artificiais conectados em camadas, que aprendem ajustando a força de cada conexão.

  1. 1
    Entrada

    Recebe os dados: números, pixels de uma imagem, palavras.

  2. 2
    Camadas ocultas

    Cada neurônio combina o que recebe, dá um peso a cada informação e passa adiante.

  3. 3
    Saída

    Entrega a resposta: uma previsão, uma classificação, a próxima palavra.

Como o neurônio decidia

Disparar ou não disparar?

  1. 1
    Sinais excitatórios

    Estimulam o neurônio: cada sinal ativo soma +1.

  2. 2
    Limiar de disparo (threshold)

    O mínimo para disparar: se a soma chega ao limiar θ, ele dispara.

  3. 3
    Sinais inibitórios

    Funcionam como veto: um único sinal ativo impede o disparo.

  4. 4
    Ativação binária

    Tudo ou nada: a saída é 0 ou 1, como um interruptor liga/desliga.

1 · Estrutura básica

Cada entrada tem um peso

  1. x
    Entradas (x)

    Os dados que chegam, como os pixels de uma imagem: 0 ou 1.

  2. w
    Pesos (w)

    A importância de cada entrada: positivo puxa para o 1, negativo para o 0.

  3. Σ
    Soma ponderada

    Cada entrada vezes o seu peso, e tudo somado.

  4. H
    Função degrau (Heaviside)

    Se a soma passar de 0, a saída é 1; senão, é 0.

A limitação

Só sabia traçar uma reta

  1. 1
    Linearmente separável

    Se uma reta divide as classes, como no E (AND), ele aprende.

  2. 2
    O problema do XOR

    No “OU exclusivo”, nenhuma reta separa os pontos: sempre sobra um erro.

  3. 3
    Uma camada só

    Com uma única camada de neurônios, a fronteira é sempre uma reta. O XOR precisaria de duas.

  2. E

  6. σ

Como a rede aprende

Backpropagation

O que é?

A retropropagação do erro: a rede compara a resposta com o gabarito e manda o erro de volta, camada por camada, para ajustar cada peso.

  1. →
    Forward pass (ida)

    Os dados vão da entrada até a saída e a rede dá um palpite.

  2. ←
    Backward pass (volta)

    O erro volta da saída até a entrada: cada peso recebe a sua parte da culpa e é ajustado.

  3. ✉
    Onde começou a ser usado
    • 1974Paul Werbos descreve a ideia na sua tese, em Harvard.
    • 1986Rumelhart, Hinton e Williams tornam o método famoso.
    • 1989Bell Labs: lê CEPs escritos à mão nas cartas dos Correios dos EUA.

Redes Neurais Convolucionais (CNN)

Redes que enxergam

O que são?

Redes feitas para imagens: um pequeno filtro desliza pela foto procurando padrões, como bordas, curvas e formas.

Lembra dos CEPs de 1989? Aquela rede de Yann LeCun já era uma CNN.

  1. vs
    MLP × CNN

    O MLP liga tudo em tudo; a CNN olha por pedaços.

  2. C
    Camada de convolução

    Um filtro 3×3 desliza e marca onde achou o padrão.

  3. A
    Camada de ativação

    A ReLU zera os negativos: só passa o que foi achado.

  4. P
    Camada de pooling

    Guarda o maior de cada bloco 2×2 e encolhe a imagem.

O Transformer

O que é?

Uma arquitetura que olha o texto inteiro de uma vez e descobre quais palavras importam para entender cada uma. É o “T” do ChatGPT.

  1. +
    Vantagem

    Treina muito mais rápido e não esquece o começo do texto.

  2. Funcionamento: 3 pilares
  3. 1
    Self-attention

    Cada palavra “presta atenção” nas que explicam o seu sentido.

  4. 2
    Processamento paralelo

    Todas as palavras são calculadas ao mesmo tempo, nas GPUs.

  5. 3
    Estrutura encoder-decoder

    Um lado entende a frase; o outro gera a resposta.

Embeddings

O que são?

Cada palavra vira uma lista de números (um vetor), que funciona como um endereço num mapa de significados.

  1. #
    Palavra → números

    A rede só entende números; o sentido fica guardado neles.

  2. ⌖
    Um mapa de significados

    Sentidos parecidos ficam perto: gato perto de cachorro.

  3. ±
    Contas com significado

    rei − homem + mulher ≈ rainha
