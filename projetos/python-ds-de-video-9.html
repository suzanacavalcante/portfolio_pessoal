Pandas Overview

Introduction to Python · Vídeo 9 de 13

Em desenvolvimento

O Pandas é a biblioteca de análise de dados do Python. Este módulo mostra por que ela existe, como criar DataFrames, selecionar e trabalhar com Series, inspecionar tipos de dados (dtypes) e fazer operações elemento a elemento.

Os trechos de código abaixo são exemplos escritos por mim com base no resumo da demonstração, não a cópia do notebook do curso. O ambiente é o mesmo dos módulos anteriores: Serverless Environment Version 5, com o ambiente base em Standard Version 5.

Por que o Pandas existe

  • Listas, dicionários e tuplas são flexíveis, mas não foram feitos para análise de dados. Calcular a média de uma coluna em uma lista de listas exige laços.
  • O NumPy é rápido, mas todos os elementos de um array têm o mesmo tipo.
  • Dados reais misturam strings, inteiros, floats, datas e booleanos, e o Pandas atende isso. Ele também ajuda em automação, reprodutibilidade, versionamento e integração com pipelines de machine learning.

A importação usa a convenção pd. O Pandas já vem pré-instalado no Databricks Runtime, então não precisa de %pip install.

import pandas as pd

DataFrame

As duas estruturas principais são o DataFrame e a Series. O DataFrame é uma tabela 2D com colunas nomeadas, possivelmente de tipos diferentes, como uma planilha manipulada por código.

Uma forma de criá-lo é a partir de uma lista de listas, em que cada lista interna é uma linha. Sem nomes, as colunas ficam 0, 1, 2. O índice das linhas é automático e começa em 0.

data = [["Alice", 30, "Engineer"],
        ["Bob", 30, "Analyst"],
        ["Carol", 40, "Manager"]]

df = pd.DataFrame(data)
print(df)
#        0   1         2
# 0  Alice  30  Engineer
# 1    Bob  30   Analyst
# 2  Carol  40   Manager

O help(pd.DataFrame) mostra os parâmetros: data, index, columns, dtype e outros. Para nomear as colunas, usa-se o parâmetro columns. O Pandas infere os tipos: name e job viram object, e age vira inteiro.

df = pd.DataFrame(data, columns=["name", "age", "job"])
print(df.dtypes)
# name    object
# age      int64
# job     object

DataFrame a partir de um array NumPy

É um padrão comum depois de cálculos numéricos no NumPy. A armadilha: arrays NumPy são homogêneos. Misturar strings e inteiros converte tudo em string, e todas as colunas viram object em df.dtypes.

import numpy as np

arr = np.array([["Alice", 30], ["Bob", 25]])   # tudo vira string
df_np = pd.DataFrame(arr, columns=["name", "age"])
print(df_np.dtypes)
# name    object
# age     object   <- a idade deixou de ser número

Series

Uma Series é uma coluna de um DataFrame: um array 1D com rótulo e índice. Pode ser selecionada por colchetes (df["age"], a forma preferida) ou por atributo (df.age).

print(df["age"])   # forma preferida
print(df.age)      # por atributo: mesmo resultado

Operações vetorizadas

Aplicam-se a todos os elementos de uma Series de uma vez, sem laço nem list comprehension. Dá para somar duas Series e misturá-las com valores escalares. Para pegar um único valor por posição, usa-se o índice.

age = df["age"]

print(age + age)       # 60, 60, 80
print(age * 3 - 1)     # 89, 89, 119: operação com escalares
print(df["age"][0])    # 30 (tipo int64)

Selecionando subconjuntos

Várias colunas

Passando uma lista de nomes, o resultado é um DataFrame (por isso os colchetes duplos):

print(df[["name", "age"]])

iloc: seleção por posição

O iloc (integer location) seleciona por posição, no formato df.iloc[linhas, colunas]. É útil em código genérico, que não depende dos nomes das colunas.

ExpressãoO que devolve
df.iloc[:, [0, 2]]Todas as linhas e as colunas 1 e 3 (name e job)
df.iloc[[0]]A primeira linha, como DataFrame
df.iloc[0, :]A primeira linha, como Series
df.iloc[0, 0]A primeira célula
df.iloc[:, 0]A primeira coluna inteira

Modificações: novo objeto contra in-place

Por padrão, as operações que "modificam" um DataFrame retornam um novo objeto e deixam o original intacto. Isso torna os pipelines mais seguros, mas é uma fonte comum de bugs quando se esquece de atribuir o resultado, o mesmo raciocínio dos métodos non-in-place do módulo de coleções.

df.drop("age", axis=1)                 # mostra o resultado, mas o df não muda
df_no_age = df.drop("age", axis=1)     # para guardar, atribui-se a uma variável

O parâmetro axis diz o eixo: colunas = 1 e linhas = 0.

Com inplace=True, o DataFrame é alterado diretamente, e a mudança é permanente. Rodar a célula de novo dá erro, porque a coluna já não existe. Por isso vale usar com cuidado.

df.drop("age", axis=1, inplace=True)   # altera o df de forma permanente
# rodar de novo: KeyError, a coluna "age" não existe mais

O que guardar: o DataFrame é uma tabela com colunas nomeadas, e cada coluna é uma Series. O Pandas infere os dtypes, e arrays NumPy misturados viram object. As operações vetorizadas dispensam laços, e o iloc seleciona por posição. As operações devolvem novos objetos, e as mudanças se mantêm com atribuição ou inplace=True, sem esquecer o papel do axis.
