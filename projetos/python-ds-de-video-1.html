Expressões e comentários

O Python avalia expressões matemáticas diretamente, e uma célula com 1 + 1 devolve 2. O caractere # marca o início de um comentário: ele não é executado e serve só para explicar o que o código faz. Se uma linha de texto comum fosse descomentada, daria erro, porque o Python tentaria executá-la como código.

# Isto é um comentário: o Python ignora a linha
1 + 1   # resultado: 2

Os quatro tipos de dados principais

Cada tipo representa um tipo de valor e oferece um conjunto de operações. Entender o tipo é essencial, porque as operações disponíveis dependem dele.

TipoO que éExemplo
Inteiro (int)Número inteiro, sem parte decimal. Pode ser positivo, negativo ou zero42, -7, 0
Float (float)Número de ponto flutuante, com ponto decimal3.14, 1.
String (str)Sequência de caracteres entre aspas simples ou duplas"Hello"
Booleano (bool)Tipo binário, com só dois valoresTrue, False

Inteiros

Aceitam adição, subtração, multiplicação e divisão. O Python segue a precedência matemática padrão: multiplicação primeiro, depois adição e subtração. Por isso 2 * 3 + 5 - 1 dá 10.

Floats

Usados quando é preciso precisão fracionária, como em porcentagens, medições e cálculos financeiros. Em caso de dúvida sobre o tipo de um valor, a função type() mostra qual é. Um detalhe: 1. é um float, porque o ponto decimal sinaliza ponto flutuante mesmo sem dígitos depois dele.

print(1.2 * 2.3 + 5.5)   # 8.26
print(type(1.2))         # <class 'float'>
print(type(1.))          # <class 'float'>

Precisão: inteiros contra floats

Os inteiros do Python têm precisão ilimitada: não há limite superior para o tamanho de um inteiro, ao contrário de linguagens como C e Java, onde ele estoura em um tamanho fixo. Um inteiro de 200 noves, somado a 1, vira um número de 201 dígitos com todos os dígitos corretos.

Os floats são diferentes. O Python não consegue representar com exatidão todos os decimais, então arredonda internamente para o valor mais próximo que consegue guardar. Os floats padrão têm cerca de 15 a 17 dígitos de precisão, o que importa em cálculos financeiros e medições científicas.

grande = int("9" * 200)       # inteiro de 200 dígitos
print(grande + 1)             # 1 seguido de 200 zeros (201 dígitos), tudo correto

print(0.99999999999999999 + 0.00000000000000001)   # 1.0, com perda de precisão escondida

Strings

Texto com números, letras, pontuação e espaços. Com o operador +, as strings são concatenadas, ou seja, unidas, em vez de somadas. O espaço entre elas precisa ser incluído explicitamente. Já somar uma string com um inteiro dá TypeError: é preciso converter o inteiro com str() antes.

Para textos com várias linhas, existem as aspas triplas, simples ou duplas, que preservam as quebras de linha dentro do bloco, sem precisar de caracteres de escape.

print("Hello" + "123")        # Hello123
print("Hello" + " " + "123")    # Hello 123
# print("Hello" + 123)          # TypeError: só é possível concatenar strings
print("Hello" + str(123))       # Hello123

texto = """Primeira linha
Segunda linha
Terceira linha"""
print(texto)                    # preserva as quebras de linha

Booleanos

Base da lógica condicional. Aceitam as operações or, and e not. O Python diferencia maiúsculas de minúsculas, então os valores são escritos com inicial maiúscula: True e False.

OperaçãoQuando é verdadeiraExemplo
orBasta um dos lados ser verdadeiroTrue or False dá True
andOs dois lados precisam ser verdadeirosTrue and False dá False
notInverte o valornot False dá True

Variáveis

Uma variável guarda o resultado de uma expressão para ser usada depois, e o valor é atribuído com o sinal de igual. Há regras para os nomes:

  • começam com uma letra ou um sublinhado, nunca com um número;
  • só podem ter caracteres alfanuméricos e sublinhados;
  • diferenciam maiúsculas de minúsculas, então age, Age e AGE são três variáveis distintas.

O valor é calculado no momento da atribuição

Se a = 3, b = 2 e c = a * b, então c vale 6. Mudar b depois não atualiza o c retroativamente, porque c recebeu o resultado da conta no momento em que ela foi avaliada. Para atualizar, é preciso executar a atribuição de novo.

a = 3
b = 2
c = a * b
print(c)    # 6

b = 4
print(c)    # continua 6

c = a * b
print(c)    # agora 12

O estado vive na sessão

As variáveis persistem entre as células de uma mesma sessão: definida em uma célula, a variável pode ser usada em outra. Mas se o compute for desanexado ou a sessão reiniciada, o estado da memória é apagado. O código continua lá, mas é preciso executar as células de novo para restaurar os valores. Dá para testar no menu Serverless, com Terminate, reanexando e rodando de novo.

Tipagem dinâmica

Uma variável pode guardar qualquer tipo de valor e ser reatribuída a um valor de outro tipo a qualquer momento, o que contrasta com linguagens como C e Java.

b = "Hello World"
print(type(b))   # <class 'str'>

b = 10
print(type(b))   # <class 'int'>

Convenções de nomenclatura

  • Usar snake_case: tudo em minúsculas, com as palavras separadas por sublinhado. Não usar camel case.
  • Usar nomes descritivos, que reflitam o conteúdo. Para distinguir, first_name e last_name em vez de um único name para vários fins.
  • Evitar nomes excessivamente longos, difíceis de digitar toda hora.
  • Não reutilizar o mesmo nome para valores sem relação dentro do mesmo script.

Exibindo valores com print

Nos notebooks do Databricks e do Jupyter, o resultado da última linha de uma célula é exibido automaticamente. Para exibir mais de um valor, é preciso usar print, que funciona com qualquer tipo de dado.

a = 1
b = 2
a          # não aparece: não é a última linha
b          # aparece: é a última linha da célula

print(a)   # 1
print(b)   # 2
print(10, "Hello world", True)

Formatando com f-strings

Há duas formas de incorporar variáveis em strings. O método format usa chaves como espaços reservados. As f-strings, introduzidas no Python 3.6, são mais legíveis e concisas: as variáveis, e até expressões, vão dentro das chaves.

a = 1
b = 2

print("A soma de {} e {} é {}".format(a, b, a + b))   # forma mais antiga
print(f"A soma de {a} e {b} é {a + b}")               # f-string

Largura de coluna e casas decimais

Os espaços reservados das f-strings aceitam largura de coluna. Por padrão, números são alinhados à direita e strings à esquerda. Com isso dá para montar uma tabela alinhada, e o .2f limita um float a duas casas decimais.

print(f"{'City':<15}{'Temperature':<15}{'Humidity':<15}")
print(f"{'Recife':<15}{30:<15}{78.456:<15.2f}")
print(f"{'Curitiba':<15}{18:<15}{65.1:<15.2f}")

Controlando sep e end

Por padrão, o print separa vários argumentos com um espaço e termina cada chamada com uma nova linha. Dá para trocar isso: sep define a string colocada entre os argumentos e end define a string anexada ao final.

print(1, 2, 3)                    # 1 2 3
print(1, 2, 3, sep="--", end=".") # 1--2--3.
print(1, 2, 3, sep="###", end="end")
print(1, 2, 3, sep="", end="$")   # 123$
print(4, 5, 6, sep="\t", end="Done")  # tabulação entre os números

Operador ternário

Também chamado de expressão condicional, é uma forma concisa de atribuir um valor a uma variável com base em uma condição.

is_tasty = True
food = "Delicious" if is_tasty else "Not Delicious"
print(food)   # Delicious

Se is_tasty fosse False, a variável receberia "Not Delicious".
