Functions

Introduction to Python · Vídeo 3 de 13

Em desenvolvimento

Funções são um dos blocos de construção mais importantes do Python: permitem definir uma lógica reutilizável, manter o código organizado e evitar repetição. Este módulo cobre como definir e chamar funções, passar argumentos, usar valores padrão e return, documentar com type hints, comentários e docstrings, entender o escopo das variáveis, usar funções integradas e escrever funções lambda.

Os trechos de código abaixo são exemplos escritos por mim com base no que a demonstração descreve, não a cópia do notebook do curso. O ambiente é o mesmo dos módulos anteriores: Serverless Environment Version 5, com o ambiente base em Standard Version 5.

Definindo e chamando funções

Uma função é um bloco de código nomeado que pode ser chamado sempre que necessário. A sintaxe começa com a palavra-chave def, seguida do nome da função (que deve descrever o que ela faz), dos parâmetros entre parênteses e de dois-pontos. Abaixo vem o corpo da função, indentado. O print que já usamos é uma função integrada.

O primeiro exemplo converte uma quantia fixa de 10 dólares para euros, com taxa de 0,93. Ela não tem parâmetros, ou seja, faz um trabalho exato com uma entrada exata, o que serve para focar na estrutura.

def ten_dollars_to_euros():
    print(10 * 0.93)

Executar essa célula guarda a definição na memória, mas nada é impresso: definir uma função não é o mesmo que chamá-la. A chamada usa o nome da função seguido de parênteses:

ten_dollars_to_euros()   # 9.3

Ao encontrar uma chamada, o Python salta para o corpo da função, executa o código ali e depois volta para a linha imediatamente após a chamada. Por isso, uma chamada entre dois print aparece exatamente entre os dois na saída.

Parâmetros e argumentos

A primeira função só converte US$ 10. Em código real, a função precisa trabalhar com muitas entradas, e isso se faz com parâmetros.

  • Parâmetro: o nome da variável escrito na definição da função, um espaço reservado.
  • Argumento: o valor real passado quando a função é chamada.
def dollars_to_euros(dollar_amount):
    print(dollar_amount * 0.93)

dollars_to_euros(5)    # 4.65
dollars_to_euros(10)   # 9.3
dollars_to_euros(20)   # 18.6

A lógica é escrita uma vez e usada com dados diferentes, que é o motivo de as funções serem úteis.

Vários parâmetros

Um segundo parâmetro, conversion_rate, permite variar também a taxa. Ao chamar a função, é preciso dar um valor para cada parâmetro, separados por vírgula. Omitir um argumento gera um TypeError.

def dollars_to_euros_with_rate(dollar_amount, conversion_rate):
    print(dollar_amount * conversion_rate)

dollars_to_euros_with_rate(10, 0.93)   # 9.3
dollars_to_euros_with_rate(5, 1)       # 5
# dollars_to_euros_with_rate(5)        # TypeError: falta o argumento conversion_rate

Argumentos posicionais e nomeados

Até aqui a posição decidia tudo: o primeiro argumento vai para o primeiro parâmetro, o segundo para o segundo. É a invocação posicional. O Python também permite nomear o parâmetro ao passar o valor, a invocação nomeada, e aí a ordem deixa de importar, porque fica claro qual valor pertence a qual parâmetro.

dollars_to_euros_with_rate(10, conversion_rate=0.93)    # 9.3
dollars_to_euros_with_rate(conversion_rate=0.93, dollar_amount=10)   # ordem livre

# dollars_to_euros_with_rate(10, dollar_amount=0.93)
# TypeError: dollar_amount recebeu dois valores

Regra: argumentos posicionais vêm primeiro, e os nomeados depois. Depois que se começa a nomear, o Python não tenta mais adivinhar pela posição. Para lembrar: começar amplo, com a posição, e ficar mais específico, com os nomes. O argumento posicional sempre tem prioridade, e dar dois valores ao mesmo parâmetro é erro.

Valores padrão

Um parâmetro pode ter um valor padrão, o que torna o argumento opcional. Na função abaixo, a taxa padrão é 0,93. Quem quiser pode sobrescrevê-la. Os parâmetros com padrão devem sempre vir depois dos obrigatórios na assinatura.

def dollar_to_euro_with_default(dollar_amount, conversion_rate=0.93):
    print(dollar_amount * conversion_rate)

dollar_to_euro_with_default(10)        # usa 0.93 e imprime 9.3
dollar_to_euro_with_default(10, 0.5)   # sobrescreve o padrão e imprime 5.0

print contra return

Esta é uma das distinções mais importantes das funções do Python: imprimir um valor não é o mesmo que retorná-lo. O print exibe algo na tela, mas não devolve o valor ao restante do programa. O Python só guarda o resultado de uma chamada se a função o retornar explicitamente. Sem return, o resultado é None.

def dollar_to_euro_with_default(dollar_amount, conversion_rate=0.93):
    print(dollar_amount * conversion_rate)

a = dollar_to_euro_with_default(10)   # imprime 9.3 na chamada
print(a)                              # None: a função exibiu, mas não retornou

Com a palavra-chave return, o Python sai da função imediatamente e devolve o valor ao chamador.

def dollar_to_euro_with_default(dollar_amount, conversion_rate=0.93):
    return dollar_amount * conversion_rate

a = dollar_to_euro_with_default(10)
print(a)   # 9.3: agora é um valor reutilizável

O valor retornado pode ser guardado em uma variável, passado para outra função, comparado em um if ou usado em uma expressão maior. Se a ideia é só exibir algo, print basta. Se o restante do programa vai trabalhar com o resultado, é preciso return.

Type hints, comentários e docstrings

Depois que as funções funcionam, o passo seguinte é torná-las fáceis de entender para as pessoas.

Type hints

Anotam os tipos que a função espera e devolve. Na demonstração, dollar_amount e conversion_rate são float, e o retorno também. Isso não faz o Python bloquear um tipo diferente: com um inteiro, a função continua funcionando. Com uma string, dá erro, mas porque a multiplicação falha, e não por causa da anotação.

def dollar_to_euro_with_default(dollar_amount: float, conversion_rate: float = 0.93) -> float:
    return dollar_amount * conversion_rate

dollar_to_euro_with_default(10)     # funciona, mesmo com int
# dollar_to_euro_with_default("10") # erro: a multiplicação com a string falha

Comentários

Anotações em texto simples, com #. O objetivo é explicar o que acontece ou, principalmente, por que algo foi escrito de certa forma. Vale evitar comentar cada linha óbvia e usar os comentários para o seu eu do futuro e para outras pessoas.

Docstrings

São mais formais que um comentário: uma string entre aspas triplas no topo do corpo da função, que descreve o que ela faz, quais parâmetros espera e o que retorna. Elas ficam guardadas na memória, e a função integrada help as lê, o que ajuda quando se encontra uma função desconhecida.

def dollar_to_euro_with_default(dollar_amount: float, conversion_rate: float = 0.93) -> float:
    """Converte um valor em dólares para euros.

    Parâmetros:
        dollar_amount (float): valor em dólares.
        conversion_rate (float): taxa de conversão. Padrão: 0.93.

    Retorna:
        float: o valor em euros.
    """
    return dollar_amount * conversion_rate

help(dollar_to_euro_with_default)   # imprime a docstring

Genie Code com docstrings

O Genie Code pode criar comentários e docstrings, e também funciona no sentido contrário: dá para usar comentários e docstrings como prompt para ele escrever o código. Na demonstração, a docstring foi colada em uma célula do Genie Code com o pedido "crie uma função com base nesta docstring", e ele devolveu a mesma função, com os parâmetros e o return.

Escopo de variáveis

Escopo é onde uma variável é visível e utilizável. Uma variável criada dentro de uma função existe só ali. Fora dela, tentar usá-la gera NameError, e isso é bom: o escopo mantém as variáveis contidas, para que uma parte do programa não interfira acidentalmente em outra.

def minha_funcao():
    func_variable = 1
    return func_variable

print(minha_funcao())   # 1
# print(func_variable)  # NameError: a variável só existe dentro da função

Funções integradas

O Python já traz muitas funções prontas, que poupam de reinventar ferramentas comuns. Além de print e help, a demonstração mostra duas:

  • max: devolve o maior de um conjunto de valores.
  • len (length): devolve o número de itens de uma sequência.
print(max(1, 2))    # 2
print(len("abc"))   # 3

E é possível chamar help em qualquer função integrada para saber o que ela faz.

Funções lambda

Uma lambda é uma função anônima e pequena: não tem nome definido com def. Serve para expressões curtas, não para lógica longa de várias etapas. Se a função está ficando complexa, def é a melhor escolha.

Na sintaxe, a parte antes dos dois-pontos são os parâmetros, e a parte depois é a expressão que o Python avalia e retorna automaticamente.

add_ten = lambda a: a + 10
print(add_ten(5))    # 15
print(add_ten(22))   # 32

A lambda pode ser atribuída a uma variável e chamada como uma função comum, inclusive com valor padrão. Funciona e é compacta, mas é menos descritiva e mais difícil de documentar. Para converter dólares em euros, a própria demonstração prefere uma função com def.

dollars_to_euros_lambda = lambda dollar_amount, conversion_rate=0.93: dollar_amount * conversion_rate

print(dollars_to_euros_lambda(10))        # 9.3
print(dollars_to_euros_lambda(10, 0.5))   # 5.0

O verdadeiro poder: passar a lambda como argumento

As lambdas brilham quando passadas diretamente para outra função. O exemplo ordena taxas de câmbio da menor para a maior com a função integrada sorted. Segundo o help, ela recebe um iterável, um objeto que devolve seus itens um de cada vez (listas, dicionários e tuplas, vistos no próximo módulo), e devolve uma nova lista em ordem crescente. A lambda diz por qual critério ordenar.

rates = {"GBP": 0.79, "JPY": 149.50, "EUR": 0.93}

sorted_rates = sorted(rates, key=lambda moeda: rates[moeda])

for moeda in sorted_rates:
    print(moeda, rates[moeda])
# GBP 0.79
# EUR 0.93
# JPY 149.5

O for usado para percorrer o resultado é o assunto de um módulo mais à frente.

O que guardar: uma função é um bloco reutilizável. Parâmetros recebem a entrada, e argumentos são os valores reais. Valores padrão tornam entradas opcionais, e return devolve o resultado ao programa, o que print não faz. Type hints, comentários e docstrings deixam as funções mais fáceis de entender. O escopo limita onde as variáveis existem, as funções integradas poupam trabalho, e as lambdas são uma forma compacta de escrever funções curtas.
