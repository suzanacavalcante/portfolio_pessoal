Em desenvolvimento

Bibliotecas são o que transforma o Python em uma ferramenta de dados: código pronto, escrito por outras pessoas, que se instala e se importa em vez de reescrever. Este módulo mostra como executar outro notebook com %run, o que é o PyPI, a diferença entre instalar e importar, os três padrões de importação, os fundamentos do NumPy e o uso do help().

Os trechos de código abaixo são exemplos escritos por mim com base no resumo da demonstração, não a cópia do notebook do curso. O ambiente é o mesmo dos módulos anteriores: Serverless Environment Version 5, com o ambiente base em Standard Version 5.

O comando mágico %run

O %run executa outro notebook e traz todo o estado dele (funções, classes e variáveis) para o notebook atual. É um jeito de reaproveitar código e configurações.

  • Deve estar no topo da célula, sem nenhum outro código Python na mesma célula.
  • O caminho pode ser relativo ou absoluto, e .. sobe níveis de pasta.
%run ../../includes/run_example

Na demonstração, o notebook run_example define uma função greet(name) e imprime "Setup complete." ao rodar. Depois do %run, a função já está disponível no notebook atual:

greet("Bob")   # funciona, porque o estado do outro notebook foi trazido pelo %run

Biblioteca padrão, PyPI e instalar contra importar

A biblioteca padrão do Python (como math e datetime) é pequena e de uso geral. Para o resto, existe o PyPI (Python Package Index), uma espécie de "app store" de código Python, com centenas de milhares de bibliotecas. Algumas das mais populares:

  • NumPy: computação numérica.
  • Pandas: análise de dados, assunto do próximo módulo.
  • Scikit-learn: machine learning.
  • Matplotlib: visualização, em um módulo futuro.

O Databricks Runtime já vem com muitas bibliotecas pré-instaladas, incluindo o NumPy.

%pip install

Para bibliotecas que não vêm no runtime, usa-se o %pip install.

%pip install numpy

Atenção: o %pip reinicia o interpretador Python. Por isso ele deve ficar no topo do notebook, para não perder os resultados das células anteriores.

O help(pip) lista os comandos disponíveis, como install, uninstall, freeze e inspect. A opção -h é equivalente a --help.

Três padrões de importação

PadrãoExemploObservação
importimport numpy, depois numpy.sqrt(4)Notação de ponto, como nos métodos de objetos
import ... asimport numpy as np, depois np.sqrt(4.0)np é a convenção universal
from ... importfrom numpy import sqrtSó a função importada fica disponível
 
import numpy
print(numpy.sqrt(4))      # 2.0

import numpy as np
print(np.sqrt(4.0))       # 2.0

from numpy import sqrt
print(sqrt(16))           # 4.0: sem prefixo, mas só o sqrt foi importado

O Python não tem uma raiz quadrada integrada, por isso o sqrt vem do NumPy. Em projetos maiores e em código compartilhado, o import com alias tende a ser mais claro, e a escolha entre os três padrões é um equilíbrio entre concisão e legibilidade.

Fundamentos do NumPy

O NumPy é a base da computação numérica no Python. O Pandas é construído sobre ele, e o Scikit-learn usa arrays NumPy como formato principal. Sua estrutura central é o ndarray (N-dimensional array): todos os elementos têm o mesmo tipo, e ele é otimizado para operações matemáticas rápidas, ao contrário de uma lista comum do Python.

Criando arrays

import numpy as np

print(np.array([1, 2, 3, 4, 5]))              # 1D
print(np.array([[1, 2, 3], [4, 5, 6]]))       # 2D: 2 linhas x 3 colunas

print(np.zeros(4))          # [0. 0. 0. 0.]: espaço reservado
print(np.ones(3))           # [1. 1. 1.]
print(np.arange(0, 10, 2))  # [0 2 4 6 8]: equivalente ao range

O dtype

O array tem um tipo de dado, o dtype. Ele é inferido dos valores (geralmente int64 para inteiros e float64 para floats), e também pode ser definido explicitamente:

print(np.array([1, 2, 3]).dtype)                    # int64
print(np.array([1.0, 2.0, 3.0]).dtype)              # float64
print(np.array([1, 2, 3], dtype=np.float32).dtype)  # float32

Indexação e fatiamento

Funcionam como nas listas, e também em arrays 2D:

arr = np.array([10, 20, 30, 40, 50])

print(arr[0])      # 10
print(arr[-1])     # 50
print(arr[1:4])    # [20 30 40]
print(arr[::2])    # [10 30 50]
print(arr[::-1])   # [50 40 30 20 10]

arr2d = np.array([[1, 2, 3], [4, 5, 6]])
print(arr2d[1, 2])   # 6: linha 1, coluna 2

Funções de agregação

Funções como sum, mean, max, min e o desvio padrão (std) operam sobre o array inteiro em uma única chamada. Usam código compilado e otimizado, não laços do Python, e por isso são rápidas.

grades = np.array([7.5, 8.0, 6.5, 9.0, 8.5])

print(grades.sum())    # 39.5
print(grades.mean())   # 7.9
print(grades.max())    # 9.0
print(grades.min())    # 6.5
print(grades.std())    # desvio padrão

help()

Ler documentação é tão importante quanto escrever código. O help(np) mostra a documentação do pacote, e o help(np.sqrt) mostra os parâmetros e o retorno de uma função específica.

help(np.sqrt)

O que guardar: o PyPI é o repositório online de pacotes, com centenas de milhares de bibliotecas. O %pip install instala no notebook e deve ficar no topo, porque reinicia o interpretador. Os três padrões de importação (import, import as e from import) trocam concisão por legibilidade. Os arrays NumPy são uma alternativa rápida, de tipo consistente e multidimensional às listas, e o help() dá a documentação na hora. O próximo módulo trata do Pandas, para análise de dados.
